## Current Project

### [qio](https://github.com/3hunnaDev/qio-public)

Collection-first, self-hosted, retrieval-first RAG platform.

- `Node.js` / `TypeScript` API and worker architecture
- `PostgreSQL` as durable workflow truth
- `Qdrant` for dense retrieval
- `Postgres FTS + pg_trgm` for lexical retrieval
- `Redis Streams` for transport and background coordination
- `MinIO` for artifacts and replayable ingestion outputs
- `Ollama` for embeddings and generation
- `OpenTelemetry`, `Tempo`, `Loki`, `Grafana`, and `Prometheus` for observability

The project is built around explicit collection boundaries, grounded answers, and a production-like local runtime instead of a toy single-process stack.
